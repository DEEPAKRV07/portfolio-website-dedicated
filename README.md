An interactive 3D personal portfolio that presents my work in AI/ML, computer vision and software engineering through a neural-network-inspired web experience.

## Concept

Instead of a conventional static portfolio, this project uses a browser-rendered 3D environment as a visual metaphor for my interests in intelligent systems and creative technology. The goal is to combine an expressive visual identity with accessible professional content.

## Technology

- **Three.js** — 3D scene rendering
- **JavaScript** — interaction and application logic
- **HTML / CSS** — web interface and initialization screen
- **Vite** — development server and production bundling

## Run locally

```bash
git clone https://github.com/DEEPAKRV07/portfolio-website-dedicated.git
cd portfolio-website-dedicated
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The repository is configured with the `/portfolio-website-dedicated/` base path for GitHub Pages. A production build has not been independently tested as part of this documentation update.
